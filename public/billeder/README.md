# Billeder

Læg billeder til webappen i denne mappe. Understøttede filformater afhænger af browseren; brug helst `.webp`, `.jpg` eller `.png`.

## Forslag til organisering

- `historie/` – historiske fotos og plakater
- `karneval/` – stemningsbilleder fra karnevallet
- `personer/` – portrætter og nøglepersoner
- `logoer/` – logoer og grafiske elementer

Når billederne er synkroniseret til projektet, kan de bruges med stier som `/billeder/karneval/festdag.webp`.

## Vigtigt

Repoet og deploymentet er offentlige lige nu. Upload derfor ikke fortrolige billeder, personfølsomt materiale eller billeder, I ikke har rettigheder til at dele offentligt.
